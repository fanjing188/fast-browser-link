# Fast-browser-link 2.5.0

发布日期：2026-10-31。macOS 稳定版；Chrome 和 Edge 使用同一固定扩展 ID。

## 改动

- 移除 FBL 内置 Assist 的侧栏、模型代理、任务编排、模板和包。FBL 保留受限的产品连接与页面读取器，供独立的 fast-browser-assist 使用；独立产品仍须另行完成等价验收和安装发布。
- 增强局部页面解析、增量快照和续读，继续绑定原任务、文档及租约。跨页面操作、未知写入和标签收组由唯一浏览器执行底座维护。
- 脚本返回对象改由 CDP 自有属性描述有界读取，不执行页面自定义 `toJSON` 或 getter；超时清理回执有独立上限，对象组按求值隔离。
- 将 Python SDK、脚本和网站工具统一到本机执行底座。诊断读取不启动服务或续期任务；执行前准备失败与已派发后结果未知分开处理。
- 新增当前页静态成品包导出与产品配对能力；退役旧云配对入口。旧任务账本、未知操作和私有配对数据不自动删除或迁移。

## 升级

已安装 Hermes 插件使用 `fast-browser-link-hermes-2.5.0.zip` 中的 `./install.sh --upgrade`；首次独立安装使用 `fast-browser-link-2.5.0.zip`。升级前运行 `./install.sh --upgrade --dry-run`，按输出处理仍在执行或结果未知的任务。升级完成后重载 Chrome/Edge 扩展，并重新加载 Hermes 插件。

## 验证范围与限制

- 独立工作树的固定 Hermes 离线门禁通过（144 个基线步骤、55 个审阅步骤，源码漂移为 0）；版本、文档、运行时检查与公开源码扫描通过。Gitleaks 扫描公开提交历史未发现密钥。
- 临时 Chrome 与 Edge 的打包模式页面读取、跨站返回、网络工具和安全序列化验收通过；两种浏览器的任务标签组清理验收通过。375 与 1440 视口弹窗截图已检查。
- 独立 Assist 已提交版对本次 FBL 接收端的组合测试通过 175/175；工作区未提交的按键／滚动实验不包含在本版中。当前个人安装的升级及发布后读回另行记录。
- 开发依赖的 `npm ci` 审计报告 5 项 moderate；运行包不含这些 npm 开发依赖，`npm audit --omit=dev` 为 0 项。
- 合成页面与临时 profile 的测试不等于真实账户、第三方供应商或独立 Assist 功能等价验收。旧安装仍需单独升级；源码或 GitHub Release 不会自动替换个人浏览器扩展。
