## 当前能力边界

- MCP 目录通知尚无常驻监听，执行前重新读取目录；是否增加监听属于后续能力选择。
- 同步系统 DNS 查询无法硬中断，返回后会检查截止并拒绝迟到发送；不能把现有总期限描述成可中断 DNS。
- Vault 适配仅支持已核实的同步合同，默认关闭；异步支持需要先解决线程归属和完整回归。
- 自由执行尚无可靠的工具级断点续跑；按[现行执行合同](design/assist.md)，重试需经任务绑定确认并从头开始，不能声称会跳过已成功的写入或付费调用。
- macOS 以外平台没有本次业务认证。设计文档中的方向也不自动成为已支持能力，实际目录见[通用任务说明](assist-tasks.zh-CN.md)。
