# 网页弹窗策略

2.6.0 未发布候选，宿主与扩展均需升级。普通新建任务默认使用“后台优先”。保护脚本覆盖可在站点脚本前安装的顶层页与子框架（包括跨进程 iframe），以及受管 `evaluate` 的 main/isolated 执行环境。页面存在 iframe 本身不会暂停任务；实际发生无法安全接管的开窗请求时暂停。已有用户页面未安装本任务保护时，本次写入以 `popup_policy_unprotected`、`reason=unprotected_document` 拒绝，不持久暂停任务；不自动刷新原页或清理草稿。

## 三种模式

| 模式 | 行为 |
|---|---|
| 后台优先（默认） | 操作期间明确使用 `noopener`/`noreferrer`、目标省略或为 `_blank`、且 URL 与源页同源的 `window.open`，转为不激活的本任务后台标签。其他弹窗先阻止并暂停后续写入。 |
| 严格拦截弹窗 | 阻止所有新的网页弹窗；发生弹窗请求时暂停后续写入，不创建替代页面。 |
| 兼容模式 | 用户显式允许网页沿原生方式开窗，保留实际 WindowProxy、opener、消息回传与关闭行为；窗口可能提升浏览器前台。 |

切换入口在扩展弹窗的当前任务“网页弹窗”控件。只作用于当前任务绑定；不会作为全局浏览器设置保存，也不沿用为下一次连接的前台许可。显式静默任务不能切兼容模式。脚本只提供 `popup_status()` 查询，没有模式切换 helper；普通网页和公开动作不能通过参数开启兼容。底层自定义代码不属于对任意绕过方式的安全隔离保证。

模式改变期间拒绝新写入；已有操作在途或宿主回执尚未结算时拒绝切换，避免半次动作跨模式。切换失败保持待核实，不回滚或重放业务动作。用户确认现场后可以“解除暂停”；此操作只重设当前策略，不重新点击、不重开之前排队的地址、不清除原生未知结果或持久工作流在途位置。切换期间新发生的拦截会重新保存暂停，不能被这次解除覆盖。

## 后台接管的边界

保护脚本在本任务空白新页完成分组、核实创建归属后安装，再导航到目标网站，避免网站先缓存原生开窗函数。后台接管不调用原始 `window.open`；受管 `noopener`/`noreferrer` 调用返回 null，符合这种调用的原生返回语义，不伪造 WindowProxy。普通后台链接继续可用既有 `open_link_in_task_tab` 显式打开。

默认和严格模式下，写操作须在本任务新开并导航的标签文档上执行。接管已有页面可先只读；若要写入，使用本任务 `new_tab` 后 `navigate` 到目标 URL，或对当前页 URL 显式 `navigate`，再重新读取快照。后者会重载当前页，调用方须先考虑未保存的页面状态。旧页面脚本可能已缓存原生 `window.open`，事后补装无法证明完整保护，因此不在旧文档上放行写入。拒绝回执给出上述操作提示且 `outcomeUnknown=false`；不需要在扩展中解除暂停。真实不安全开窗仍按原规则暂停。

只接管无歧义的逗号分隔 noopener/noreferrer 声明；冲突、否定或不支持的特征写法会暂停。只接管与发起框架同源且属于任务已批准来源的 HTTP(S) URL，拒绝 URL 用户名/密码、特殊协议、空地址、跨站或依赖命名窗口的调用。跨站登录、默认返回窗口引用的弹窗、`target` 新窗口链接与表单、原生 form.submit 都进入暂停；不会提取并重放表单内容。后台地址导航与原始页面导航的 Referer、窗口形态等行为可能不同，不能据“已建页”声明业务成功。

每次动作最多接管一个地址；混合请求或容量不足整体停止开页。任务已有四个工作页时不在当前动作中回收页面来腾位。后台子页沿同一工作区创建日志登记，并在宿主确认当前源租约、任务代次与模式代次后获得本任务新页租约；不会接管任意已有标签。登记回执丢失或开页不确定时冻结，不再发一次开页。

`popup_catalog()` 的 `backgroundTabs` 返回已管理的后台子页；`wait_until/run_steps` 的 popup 条件可观察本次新建子页。它们已属于任务，不再调用 popup_adopt；用 `use_tab(tab_id)` 显式选页后重读。出现多页后，新脚本仍须显式选择目标，不猜页面。后台子页通常没有 opener；它不能代替依赖 opener 或 postMessage 的登录窗口。

## 暂停、查询与续做

```python
state = popup_status()
# supported / mode / protected / paused / reason / coverage
```

查询不切换模式、不返回排队 URL、填写内容或控制密钥。策略暂停后仍允许快照、页面观察、目录与必要的只读核实；新写入会在派发前拒绝；故障恢复的刷新同样核验弹窗保护，不能借恢复绕过旧文档停点。`execution_status` 同时包含弹窗暂停保护，组合步骤和批量流程遇到暂停会停止，保留原动作已送达的事实。

被拦的开窗发生前，按钮的其他页面代码可能已经执行。不能把“没有弹窗”解释为“按钮未点击”。有业务后置条件的持久流程，应在人工处理后用原 DOM/URL 条件澄清，再续做；不要新建请求重放旧提交。

启动脚本可能早于租约登记：新页的暂停随可信建页回执交接，在宿主登记租约后、返回回执前落盘；后台子页则在双端租约确认后补记暂停。自动弹窗的固定暂停通知经受管调试通道上报；按任务、租约、代次和模式校验，旧模式的迟到通知不复活暂停。宿主确认暂停后持久保留人工处理标记，空闲扫描不会关闭等待处理的任务。只读查询和旧请求的缓存回执继续可取；只有扩展界面明确解除，才移除这个策略标记。通知回执异常不当作成功。

## 已知限制

- 本机 Edge 回环地址桌面复验仍未通过：后台导航到 `http://127.0.0.1` 或 `http://localhost` 可能提升浏览器窗口。等时长对照表明点击不是必要条件；完全不加载本插件、直接使用浏览器调试协议导航也能复现。普通域名映射到同一本地服务器的原生对照保持后台。已定位到 Edge 原生导航路径，但尚未修补其内部触发原因；不能用命名来源的通过覆盖回环地址失败。详见 [Edge 桌面焦点调查](edge-desktop-focus.md)。
- 同进程框架继承顶层的新文档脚本；跨进程 iframe 通过 flatten 调试会话在执行站点脚本前安装。保护安装失败时仅在该框架实际发出开窗事件后暂停；该异常路径不能保证拦住浏览器已开始创建的窗口。动态框架在受管动作中途创建、旧文档缓存的开窗引用、任意原始 CDP 上下文和特殊网站脚本仍未获得全面静默验收。
- 任意原始上下文操作不能靠执行后再抢回焦点补救；需要对应功能时，由用户选择兼容模式，或者使用受管 evaluate helper。
- 扩展重载、调试会话丢失后，不把旧标签视为已保护。保留的工作页可能需要用户重新打开；不自动重载表单。兼容模式只恢复受管开窗的透传行为，不承诺撤销所有网站此前已观察到的页面 API 差异。
- 浏览器或系统的原生对话框不在网页开窗覆盖范围。兼容模式明确允许前台窗口，不能算进静默通过数。
- 测试使用本地合成站和临时 profile；真实第三方登录、账号状态、生产提交与所有网站仍需分别验收。

## 验证入口

`tests/v1.6.0/real-desktop-download-popup.mjs` 默认无头，覆盖后台开页、双端租约、暂停不重放、严格模式、链接/表单、下载、隔离环境、兼容登录回传以及 1440/375 的实际扩展界面。Edge 加 `--edge`。真实 macOS 前台采样加 `--headed`，必须先获用户同意，使用私有 TMPDIR；只将默认/严格场景计入静默采样，兼容场景单列。采样按本次临时浏览器的实际进程身份拒绝其成为系统前台，并核实其工作窗口未聚焦；允许用户继续使用自己的应用或浏览器，不通过操作后抢回焦点掩盖问题。

离线回归同时覆盖 MAIN bootstrap、受管隔离环境、模式在途保护、旧通知拒绝、开页前保护顺序、宿主持久暂停/空闲保护和只读回执。验收结论以当前候选的报告为准。

可加 `--named-origin` 使用 `popup-policy.test`，仅在本次临时浏览器里解析到本地夹具服务器；结果写入独立的 `-named-origin` 目录，原始回环地址默认测试保持不变。该选项不修改个人 DNS、浏览器设置或站点安全检查。

按用户选择，macOS Edge 的本地 HTTP 地址继续允许访问，不自动切换浏览器或阻断任务。新建页、导航回执及页面状态携带 `backgroundFocus.code=EDGE_LOOPBACK_FOCUS_RISK` 与 `guaranteed=false`，当前任务页的扩展界面显示“任务继续执行，无法保证静默”。提示不通过系统通知或聚焦窗口展示。匹配 URL 解析后的回环主机（localhost、其子域、127/8、IPv6 回环），不把相似域名当作本机；其中 IPv6／子域使用保守提示，未逐一做桌面实测。原始 CDP 回执保持原协议，状态查询仍可查看当前页提示。
