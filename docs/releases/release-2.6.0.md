# Fast-browser-link 2.6.0

2026-11-03，新版本候选。基于正式 2.5.1（2f07a7e）；本文件不代表已公开发布或个人安装已升级。

## 改动

- 整合独立产品固定按键、上下滚动及隐藏页滚动修复，保持末端文档、资源和未知结果核验。
- 整合 Unicode 名称查询、文档根替换与点击最终复核，防止剪裁候选误报唯一或使用失效页面引用。

- 新增默认后台优先、严格拦截弹窗与用户显式兼容三种网页弹窗策略；受管同源 noopener 后台接管，不兼容暂停不重放。宿主持久暂停并保护等待处理的任务不被空闲关闭。范围与限制见 [网页弹窗策略](../popup-policy.md)。
- 新增持久检查点与逐项批量结算；同绑定、同计划续做跳过已确认步骤，在途/未知冻结，宿主核原后置条件后才可澄清。
- 新增业务进展摘要、自动 JSON/Markdown 验收报告、按来源隔离的站点模板与大小/摘要/记录/列/日期下载校验。
- 新增持久执行时间、操作与等待预算，显式调整保留耗用；接口与限制见 [持久工作流](../workflow-tools.md)。
- 修复后台输入自动切换活动标签；CDP 激活仅逻辑选页，原始键盘/文本用页面焦点模拟，不提升系统窗口。
- 自动审批提示后台建面板并通知，仅用户主动打开时聚焦；原始创建/恢复系统窗口命令拒绝，保留显式人工查看入口。
- 新增故障恢复 execution_status/recover_page/read_resilient，受保护现场不刷新，每标签最多一次，未知结果不补发。
- 新增同源共享智能降速，识别 429/503、Retry-After 和频繁提示，限制并发并在成功后逐步恢复。
- 新增连续失败熔断与同目标无进展循环保护；验证码、登录、权限及配额要求人工处理。
- 新增 `wait_until`，统一元素、地址、响应、下载、弹窗的 any/all 等待，保留覆盖和事件基线。
- 新增 `run_steps`，整组参数与 CSS 预检、动作前监听、前后条件核验、首错停止；保留已送达回执，不重放未知动作。
- 新增 `diagnose_target`，只读返回当前范围的歧义、遮挡、禁用、只读和覆盖诊断，不创建写入资格。
- 名称定位等待固定原文档、租约及文档代次；当前范围不完整或有多个可操作同名目标时拒绝派发，遮挡只等待自然消失。
- 工作流截止后宿主可能仍在执行时，当前脚本阻止继续派发，仅显式核对可解除未知屏障。
- 新能力经绑定实例 `browser_workflow_v1` 检查；SDK、JSON CLI、MCP、Hermes 复用原脚本链。打包和安装要求携带 workflow 模块，缺件拒绝。

接口、限制和例子见 [通用工作流](../browser-workflows.md)。

## 验证范围

按用户选择，macOS Edge 本地 HTTP 访问继续允许，新建页、导航回执和任务页界面明确提示静默限制；不自动切换浏览器，不阻断任务。

Edge 在回环地址（localhost／127.0.0.1）导航时仍存在桌面焦点失败；不加载插件也能复现，组合点击不是必要条件。当前不能宣称 Chrome/Edge 所有场景完全静默。具体边界见 [网页弹窗策略](../popup-policy.md)。

真实 Chrome/Edge 验收使用打包候选、本地合成页面、临时独立 profile 和私有 scratch。覆盖定位诊断、填写、响应与页面结果联合核验、后置失败停止、下载、导航、任意条件等待、超时及弹窗观察。SDK/CLI/MCP 接入另用本地临时浏览器验证；Hermes 路径通过实际脚本宿主与子进程验证。

效率对照保留三种写法：分散的三次脚本、原有单次批处理脚本、新组合接口。每种各三轮；结果不代表模型端到端、第三方网站或生产业务提速，也不证明新接口快于所有已有批处理写法。

离线回归覆盖条件组合、覆盖缺口、文档变化、事件缺口、事件基线、整组预检、实例/代次及旧能力拒绝、未知结果与传输截止不重放；实际通过情况以本次门禁报告为准。

## 安装与发布

本版本尚未打标签或公开发布。主线整合和本地安装不等于正式发布；正式发行包需在后续发布流程生成并核验。升级必须同时更新宿主与扩展并重载。保留 2.5.1 的浏览器唤醒与任务归档能力，不以本次临时浏览器验收替代个人冷启动重连验收。
