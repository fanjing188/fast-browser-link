# 导出一个多页表格

1. 在已连接浏览器打开目标表格页，保留所需筛选。打开侧栏，无需配置 Agent。
2. 点“多页采集”，选择识别到的表格。若没有表格，先让页面加载完成，或滚动到表格后重新识别。
3. 在导出面板核对列、已识别行数、页数和不完整提示。有分页时点“保存全部”；默认最多 50 页，设置可调，硬上限 200 页。
4. 核对确认卡后开始。后台工作页仅继承地址里的筛选参数，页面内尚未写入地址的筛选可能不同。不要假定全部账号数据都已采集。
5. 在“进行中”看进度。可“停止并保存部分”，结果会标注不完整。完成后从“结果”打开文件或所在目录；当前页也支持 CSV、Excel 和复制。

如页面不能确定分页，先保存当前页，核对行数与来源。没有稳定行号时，完全相同记录的跨页归属仍需核实。设置 → 表格与导出可选择默认目录。
