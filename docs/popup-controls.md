# Popup and task controls

The popup summarizes the current host connection. Its header dot represents local connectivity, not authorization for arbitrary pages. A verified connection allows Fast-browser-link to read, click, fill and execute scripts on task pages without repeated per-site or per-action approval. Connection authorization is confirmed only in the extension's own interface. Task isolation, takeover, stop and password-value redaction remain in force; no mode selector or separate access toggle is added.

The Local and Cloud information buttons expose these explanations on hover and keyboard focus. Unknown/offline state never proves usable task access, and old cached grants never prove a current connection. Cloud pairing allows direct reading, clicking and filling only on cloud-created task pages, without granting access to existing personal tabs. Disconnect and replacement pairing remain explicit actions. Nothing logs password values.

Open Assist launches the browser side panel and closes the popup only after success. Its switch changes the same local collaboration setting used by the sidebar. The cloud row expands an inline pairing panel; expanding alone neither pairs nor disconnects. Pair, regenerate, copy and disconnect require explicit UI actions. Navigation closes the popup after successful handoff; other actions keep it open. Escape first collapses pairing, then closes the popup. Errors stay until dismissed.

Task controls are scoped to the current owned page, task identity and generation. Uncertain commands are not automatically replayed. A stop receipt is shown briefly without asserting continuing ownership. The page overlay requires two stop clicks within three seconds, validates the same host receipt as before, and preserves closed-shadow isolation, first-frame preveil coverage and screenshot-time input blocking. A successful stop still tears down the blocking overlay through the existing task cleanup path. The display component supports terminal states for retained results and offline previews; it cannot keep a revoked task's blocker alive.

Logs show only the host's already redacted action summaries, never input values or raw errors. The recent eight rows are shown by default, with up to 100 host-provided rows available to expand/copy. Scrolling upward pauses following; Jump to latest resumes it. Collapse/minimize preferences are stored by the extension per task generation, not in website storage. Minimizing changes only presentation, never input interception or permissions.
