# 第一次使用 Assist

先完成[安装](installation.zh-CN.md)并连接浏览器。侧栏顶部“先试试，无需 Agent”提供四个入口：

1. **识别并导出表格**：读取当前页，选表格，再选择 Excel、CSV 或复制，核对确认后保存。
2. **多页采集**：打开同一表格面板；有分页或不完整表格时选“保存全部”。先核对页数、上限和筛选提示，再确认。
3. **页面标注**：点击后在当前页显示已有本地证据，再次点击停止。无数据保持未知；不会因此启动模型。
4. **工作篮**：可先打开空篮；用标注的＋或导出表格加入对象，批量操作仍先预览并确认。

需要主动建议时点“配置 Agent”，选择 Hermes 或 Codex 并检查连接，然后显式开启协作。配置前不展示主动流程建议；你主动识别的本地表格仍可使用。设置 → 协作 Agent 可再次配置。Codex 需先自行安装并登录，最低 CLI 版本 0.162.1；Hermes 缺少模型配置时按提示运行 `hermes model`。

Codex 受限推理实测每次固定输入约 **10.6K tokens**，另加任务上下文，实际用量可能变化。未选推理模型时从 `model/list` 按名称段依次优先 nano、mini、luna，同档保留目录顺序；无匹配沿用默认。名称是成本启发式，不是实时报价。手动选择优先，执行模型不受此规则影响。

运行中可接管或停止；密码、支付、验证码和最终提交由你完成。结果不确定时先核实页面，不重复写入。设置 → 记忆可查看、删除或关闭本地工作记忆。真实第三方网站和账号仍需单独验收。
