# Fast-browser-link 2.6.0

发布日期：2026-11-04。macOS 稳定版；Chrome 和 Edge 保持同一固定扩展 ID。

## 改动

- 后台任务拥有独立的工作窗口、分组和输入队列，避免多个任务互相切换活动标签。后台文档中的暂停过渡动画不再把可操作按钮误判为隐藏；页面遮罩与交互高亮下的语义定位可穿透插件层，同时继续检查网页自身的遮挡。
- 弹窗策略支持后台优先、严格拦截和用户显式兼容模式。开窗保护覆盖同进程和跨进程 iframe；未安装保护的已有文档只拒绝本次写入并给出重新导航提示，实际不安全的开窗才持久暂停，未知结果不重放。详见[弹窗策略](../popup-policy.md)。
- 语义快照支持 `query`、`role`、`limit` 和 `cursor`，并说明筛选、截断及不可见覆盖；无匹配查询返回空结果。错误回执按 `usage`、`site`、`plugin` 三类提供可重试性与中文处理提示，待用户批准的任务返回 `approval_pending`。`evaluate` / `js.evaluate` 要求函数表达式；非函数输入直接报 `invalid_expression`，`js.evaluate` 省略参数时也会执行函数。
- 导航可等待 load、idle、元素或文本就绪，脚本 `open_page()` 返回标签与就绪回执。`wait_until` 统一等待元素、地址、响应、下载与弹窗；`run_steps` 在派发前预检整组动作并核验后置条件；`diagnose_target` 提供只读定位诊断。详情见[通用工作流](../browser-workflows.md)。
- 执行保护提供安全读取恢复、同源限速、连续失败熔断和无进展循环停止；验证码、登录、权限、配额及未知写入仍需人工核实。持久检查点、执行预算、逐项结算、业务摘要和下载校验支持较长任务。任务关闭后生成脱敏的 Markdown/JSON 操作记录，回执提供路径。详情见[持久工作流](../workflow-tools.md)。
- 升级流程自动结算已关闭且清理成功的任务；`tasks:ack` 可自动定位数据目录并处理多个任务 ID。开发安装命令 `npm run install:dev -- --apply` 会打包、预检、安装并读回扩展构建号。

## 安装

独立模式下载 `fast-browser-link-2.6.0.zip` 并核对校验文件，解压后对已有安装先运行 `./install.sh --dry-run`，再运行 `./install.sh --upgrade`。Hermes integration 使用单独的 `fast-browser-link-hermes-2.6.0.zip`，其已有安装采用同样步骤。升级保留任务数据；运行中、待批准或结果未知的任务先按回执处理。更新后重载 Chrome/Edge 扩展，并重新加载或重启 Hermes 插件运行时。

本地独立版与 Hermes 集成版候选包均已试打并计算 SHA256；正式发布包仍须从干净、已提交的公开源码构建。

已知限制：macOS Edge 导航到 localhost／127.0.0.1 等回环 HTTP 地址时仍可能抢占桌面焦点，不加载扩展也可复现；因此不能保证所有场景静默。显式兼容弹窗模式也可能切到前台。未保护的旧文档必须重新导航或在同任务中新建页面后再写入。下载校验对 PDF/图片仅检查签名，对 XLSX 仅检查缓存值；合成文件不能证明实际业务导出完整。
