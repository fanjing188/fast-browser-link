# Edge 桌面焦点调查

状态：浏览器级复现已确认；按用户选择保留本地地址访问并明确提示静默限制。Edge 的回环地址抢焦点本身尚未消除，不能宣称所有场景完全静默。

## 本机复现条件

2026-11-04，macOS 上的 Edge 156.0.4314.58，使用独立临时 profile。后台新建空白标签，导航到只含标题的本地 HTTP 页面；约 15 秒后再次建页并导航，Edge 进程可能成为系统前台。目标标签仍可为 inactive，故不能用标签状态代替桌面验收。

## 已确认的对照

- 不执行任何点击、只保持相同等待时长，也能复现；此前把组合点击视为必要条件的判断不成立。
- 不分组、不连接扩展调试器、不运行插件任务，仍可复现。
- 完全不加载本插件，仅用临时浏览器的 CDP 创建后台标签并导航，也可复现。
- 直接启动浏览器程序与通过 macOS Launch Services 后台启动，均可复现。
- `tabs.update` 显式 `active:false`、最小化工作窗口、由页面执行 `location.replace`，均未消除本地地址失败。
- `127.0.0.1` 与 `localhost` 都复现；同一本地 HTTP 服务使用 `focus.test` 并仅在测试浏览器里映射到 127.0.0.1，原生对照保持后台。公共 HTTPS 示例页实际加载完成的对照也保持后台。

这些证据将问题定位到 Edge 对回环主机地址的原生导航路径，排除了本插件作为必要触发条件；它们不能证明 Edge 内部哪一项功能或系统调用存在缺陷，也不能推断所有版本和平台均有此问题。未关闭浏览器安全提示或网络权限检查，未修改个人浏览器配置。

## 验收边界

`tests/v1.6.0/real-desktop-download-popup.mjs --edge --headed` 保留回环地址回归；加 `--named-origin` 运行普通域名来源的独立矩阵。两者必须分别报告。所有桌面测试串行执行，采样只拒绝本次临时浏览器的 PID 成为前台，另检查其全部窗口；锁屏或无效桌面判为验收无效。正式测量期间不恢复焦点掩盖切换。

本次诊断日志位于本地忽略目录 `artifacts/popup-policy-2.6.0/`；其中重复性诊断的 `DIAGNOSTIC RESET` 仅用于调查再次导航是否复现，不属于正式静默通过证据。

## 已采用的处理

用户选择继续允许本地地址访问。插件不拦截或改写这些地址，不自动切换浏览器，也不在事后抢回焦点。macOS Edge 本地 HTTP 新建页／导航回执和页面状态增加固定的 `backgroundFocus` 风险提示，扩展界面显示相同限制；提示中不包含页面路径、查询参数或输入。原始 CDP 结果不追加非协议字段。

网页弹窗的 strict 模式改称“严格拦截弹窗”，明确它负责拦截网页弹窗，不能承诺控制浏览器自身的所有窗口行为。

命名来源桌面矩阵的本地地址提示组明确位于静默采样之外，验证仍能正常访问、回执包含风险提示、界面正确展示。它不是回环地址静默通过的证据。
