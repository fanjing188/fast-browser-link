# Fast-browser-link 2.4.0

状态：本地候选，尚未公开发布或替换个人安装。完整组合验收与发布审批待完成；本页不代表发行证明。

## 改动

- 独立 Python SDK 共享任务身份、请求账本与脚本核心，CLI/MCP 不反向加载 Hermes 入口；同名模块按真实路径隔离，增加原操作只读状态查询。
- 唯一脚本与网站工具实现位于 `native-bridge/`，无 Hermes 适配器的部署可运行真实脚本子进程及已启用网站工具。
- 移除云配对 UI、后台主动连接、云端源码和新包载荷；旧安装退役保留任务、未知操作和私有配对数据。
- 分享诊断包只提供固定级别与异常类型计数，不带任意 stderr 正文。配套 Skills 与产品版本同步校验。
- Fast-Backlink 普通/AI 填写通过精确扩展配对进入 FBL 自有页面权威和 Native 专用任务。支持顶层 light DOM 的普通 input/textarea；敏感字段、人工输入、提交锁与未知结果保持受保护，不回落另一执行器。
- 当前页 `export_page` 通过既有脚本/CDP链生成私有成品包，含渲染HTML、可读缓存前端资源及校验/覆盖清单；不重抓、爬站或还原原工程。预览清表单值并禁脚本/外联，原始JS及可见内容仍可能敏感。

## 安装

独立模式下载 `fast-browser-link-2.4.0.zip`，解压后运行 `./install.sh`；通用安装器不覆盖已有安装，升级时保留 `.fast-browser-link/plugin-data` 并遵循通用接入文档的维护要求。Hermes integration 使用单独的 `fast-browser-link-hermes-2.4.0.zip`，其已有安装使用 `./install.sh --upgrade`。更新后重载 Chrome/Edge 扩展，并重新加载或重启 Hermes 插件运行时。安装支持范围待核实。

## 验证范围

本地定向验证覆盖独立 SDK、脚本/网站工具、Assist 装配、产品页面权威与 Native 持久屏障、真实后台路由、退云与安装打包闭包。缺件安装在启动前拒绝；明确未派发的拒绝不制造永久未知锁，真正未知仍阻止新请求重放。

临时 Chrome/Edge 的原页接管与 Edge Native 工作台已取得独立验收证据。配对设置页的深浅色、中英文和窄视口矩阵已目视；消息夹具不作为真实配对证明。浏览器测试只使用私有临时 profile 和合成资料，不替代真实供应商、账号或业务保存验证。

双扩展修复后的冻结快照已在 Chrome/Edge 各通过 11 项实际组合检查，包含同 URL 更换文档后的旧意图拒绝；Codex 已复审本批生命周期修复。旧云退役安装可升级及失败回滚的锁保护已通过父会话定向复验。最终冻结版本仍须纳入新增页面导出并重新统一验收。

页面成品包已在临时 Chrome/Edge 实测预启用调试域后的连续导出、长根属性中文编码、离线样式/图片及零原站新增请求；HTML重解析回归覆盖异常根、命名空间、动态注释和未知CSS。异常head布局修复后，真实离线表单提交触发CSP阻止且没有导航，独立Codex复审无新增问题。未闭环：固定 Hermes 全量门禁及发布审批。定向验证、源码候选与个人安装状态分别记录，不用旧包或历史测试计数代表最终发行。

锁文件内两项间接开发依赖已更新至补丁版本，安装后 `npm audit` 为零漏洞；运行发行载荷不包含 npm 开发依赖。
