# 浏览器执行底座

## 职责与依赖方向

Fast-browser-link 提供本机浏览器执行能力，工作插件通过 SDK 使用同一执行器。浏览器底座不判断外链准入、不维护产品资料，也不替工作插件认定业务成功。Hermes、CLI、MCP 是接入层；Assist、Fast-Backlink 是工作产品，不是授权来源。

```text
Fast-Backlink / Assist / 其他工作产品
                 ↓
           本机 SDK 与接入层
                 ↓
       任务、租约、操作账本与执行器
                 ↓
        Native Messaging 与浏览器扩展
```

本机执行不需要云端配对或中转。新版本不提供云端连接入口和云端宿主；升级仍须保护旧版遗留任务、私有数据和可回滚材料，不因停用功能而清空未知操作。

## Python 接入

`native-bridge/browser_sdk.py` 是框架无关入口。`Browser`、`METHODS` 和 `session_owner` 由独立 CLI/MCP 入口复用；工作插件直接加载已验证安装中的 SDK，不调用 Agent 的命令行解析器，不复制底层客户端。

- `Browser.call(operation, params)` 沿用 [Native 协议](design/protocol.md)，参数仍为 camelCase。
- 每个调用方使用自己的可信会话身份。公共参数不能指定 owner、租约或宿主身份。
- `create` 显式传 `existingTab` 接管当前页或唯一精确 URL；不接受调用方任意指定原页 tabId。歧义、连接变化或租约冲突必须拒绝。
- `run` 自动生成请求编号。真正未知结果不重试；核实只读当前页面或原操作状态。
- `close` 显式传 `keepTabs` 和 `handoffReason` 才交还页面。Python 客户端的 `close()` 仅关闭本机连接，不暗中关闭或交接业务页面。
- 业务产品负责停止后的任务释放，并保留提交未知状态。关闭连接不是关闭任务的证明。

SDK 是本机可信代码接口，不是任意第三方代码沙箱。保护文件、浏览器连接授权、敏感字段、任务租约、原页资格和代次检查继续生效。不能把有能力调用 SDK 等同于用户授权了最终提交。

## 核心与 Assist 装配

`daemon.py` 直接运行提供纯浏览器服务，不导入或自动发现 Assist。完整产品默认由固定的 `assist_adapter.py` 启动，显式装配 Assist 的产品路由、资源关联、连接和关闭生命周期；产品模块按需要初始化。SDK 本身不初始化 Assist，纯核心不接受产品私有授权字段。

安装复制和维护进程身份同时包含固定 bootstrap；缺件明确拒绝，不回退源码目录启动另一版本。维护仅接受原目录内 `daemon.py` 或 `assist_adapter.py` 加精确 `--home` 的进程，不能按文件名后缀猜测任意进程。

## Fast-Backlink 首批接入边界

首批以用户显式触发的一键填写为验收路径。资料、字段映射、业务账本及界面归 Fast-Backlink；页面读取、执行所需的业务保护和实际普通字段写入归浏览器底座。

执行边界是唯一运行时，不只是共享源码。Fast-Backlink 保留资料、匹配/AI建议及业务界面；FBL 自有扩展隔离上下文维护本页执行所需的业务绑定、人工修订、单调提交锁和单次许可，并在同一同步调用栈内完成最后资格复核与写入。Backlink 的页面状态只作展示，不能授权另一个 setter。

项目切换先撤销旧绑定并取得页面屏障回执，再安装新绑定和确认切换；暂停后旧许可不能恢复。屏障不回滚此前写入，也不保证撤回已派发的浏览器动作。产品专用任务不得使用普通填写、脚本、原始 CDP 或私有凭据入口绕过业务保护。未知 commit 在扩展和 Native 中保留单调屏障，不能换 requestId、重新 bind 或关闭后新 attach 重放。此接入已形成未发布候选，真实双扩展与最终门禁尚待验证。

接入必须同时核原页面、文档、字段身份和产品/任务代次；可信选页入口即冻结浏览器 documentId，审批前后及首次注入精确限定同一文档，同 URL 重载不继承旧业务意图。跨进程前通过一次资格检查不能代替真正写入时的复核。写入后结果未知不得退回旧 DOM/CDP 通道重复填写。

批量投稿、最终提交、登录接续和长期待人工复原是独立迁移切片。保留现有业务合同，不为了接通新底座削弱敏感字段、排重或未知提交锁。

## 验证

- SDK 在不导入 Hermes、Assist 或 Agent 命令入口的独立进程中加载；拒绝同名应用模块污染。
- CLI、MCP 和工作插件共享身份注入、请求去重、脚本及结果合同。
- 新安装无云端注册，发行载荷无云端运行模块；旧安装升级保留在途门禁和失败回滚。
- 组合测试另验原页草稿、窗口/分组保留、停止与人工继续输入，以及未知写入不重放。

实现候选、本地通过、真实浏览器通过、安装生效与公开发布分别记录；架构约定不代表这些交付阶段已经完成。
