# Export a multi-page table

1. Open the table in the connected browser and apply your filters. Open the sidebar; no Agent setup is required.
2. Click **Multi-page collection** and select a detected table. If none appears, wait for loading or scroll to the table and detect again.
3. Review columns, detected rows, page count and incomplete-data notices. Choose **Save all** when available. The default limit is 50 pages; settings can adjust it up to the hard limit of 200.
4. Review the confirmation card and start. Background work pages inherit only filters encoded in the URL; filters held solely in page state may differ. Do not assume all account data was collected.
5. Watch progress in Running. **Stop and save partial** preserves an explicitly incomplete result. Open the file or folder from Results. Current-page export also supports CSV, Excel and copy.

If pagination cannot be determined, save the current page first and check rows and source. Without stable row IDs, identical records across pages still need review. Settings → Tables and export selects the default folder.
