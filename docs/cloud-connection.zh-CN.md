# 配对云端浏览器

云端是可选接入，与本地 Agent 授权独立。按[部署与安全合同](design/cloud-connection.md)配置自己的私有 Sites 服务及插件，凭据保存在本机受保护配置里。

1. 扩展弹窗选择“云端连接”。
2. 生成连接码，打开配对页。十二位连接码五分钟有效。
3. 核对浏览器身份并明确确认配对，再在 ChatGPT 连接该站点插件。Chrome、Edge 分别配对。

配对只授权云端新建工作页的支持操作，不授权已有个人页。接管、停止、敏感输入控制继续生效。显式断开；远端撤销未确认不等于成功。重连后先核对任务，不重放未知写入。

完成时关闭任务并检查清理回执。只有明确交接时使用 `keep_tabs=true`。[English](cloud-connection.md)
