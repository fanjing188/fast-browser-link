# Cloud connection retired

Fast-browser-link uses the local browser execution path. New packages do not provide cloud pairing, a cloud Native Messaging host or remote relay access. Use the [Agent integration](agent-integration.md) or the [local execution SDK](browser-core.md).

Upgrading must not erase unknown operation records, pairing data or credentials. An old active cloud task must be settled through its supported controls before replacement. Local program retirement does not revoke a remote account or delete a deployed service. Keep the existing rollback materials until migration is verified. [中文](cloud-connection.zh-CN.md)
