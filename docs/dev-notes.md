# 开发备注

## 2.6.0 通用工作流候选

- 用户已批准默认后台优先、不兼容暂停、显式兼容的弹窗策略及对应真实桌面验证。本批保留当前分支，不安装、推送或发布。
- 网页开窗控制只对新建页在导航前准备，私有控制闭包不提供模式切换 helper。受管 evaluate 的隔离世界必须单独安装并合并队列，未知原始上下文/框架拒绝写入；不伪造 WindowProxy 或重放表单。
- 暂停通知只收固定码并按模式纪元去重，宿主落盘后确认，保留已派发动作与旧缓存回执；人工等待受空闲保护。显式兼容只由扩展 UI 改变，模式切换与在途动作互斥，失败保持未确认。


- 新增 workflow_tools：可信宿主持久 SQLite/FULL、派发前 arm、跨进程锁与计划 HMAC；不存输入正文。超时须等实际 worker 排空再释放运行锁，保留在途位置。reconcile 的当前 DOM/URL 证据由宿主核验原计划，不能信任子进程自报成功。
- 流程锁与预算绑定本次脚本运行令牌；只读报告不拥有运行锁，旧脚本收尾不能释放后续运行的锁，其他脚本也不能串入当前预算或写入。
- 批次只继续明确未派发的项目失败；业务摘要不完整、全局保护或未知停止。预算含嵌套请求、耗用持久且显式调整不归零。报告区分确认送达与已满足后置条件。
- 桌面专项已获本次用户授权；Chrome/Edge 普通后台执行通过，旧策略的独立 window.open 实测会拉起前台，保留历史失败；新策略只声明已验证保护范围，不以恢复旧焦点遮掩。未修改个人安装。


- 后台输入修复移除 WorkWindow.input 的 tabs.update(active:true)，保留原窗口串行与归属复核；页面焦点模拟与系统焦点分离。CDP 激活只做授权逻辑选择；自动审批不抢焦点，人工主动打开可聚焦。禁止用“执行后抢回来”恢复旧焦点，以免覆盖用户途中主动切换。

- execution.guard 是固定隔离探针/状态/受限刷新，不接受任意页面代码；恢复、已知失败上报和状态查询经同一任务租约与绑定能力检查。失败上报只收当前健康令牌、固定错误码并去重，不能清除保护。
- 冷却在扩展 Executor 按同源共享，等待在页面锁外但每次等待前后核任务/模式代次；保护启用后才接管动作节奏。预算与循环状态不持久化，因此刷新要求当前运行期间的本任务新建标签证明。凭据页、表单、框架和既往潜在写入禁止刷新；刷新额度在派发前消耗。

- 基线是正式 2.5.1 的 2f07a7e，不将旧 main 的版本标记作为发行基线。工作流只组合既有 script/helper，通过绑定实例 browser_workflow_v1 检查；不新增常驻工具或业务调度。
- 后置事件必须先于动作建基线；响应游标不消费旧队列，已有下载/弹窗不匹配。后置失败保留已送达回执，未知后停止。定位等待沿用已审核遮挡修复，不关闭遮挡、不以可见性消除同名业务歧义。
- 对新功能、旧版兼容、完整门禁和真实临时浏览器分别记录证据；不把合成站效率外推到生产。

## 执行底座拆分候选

- Assist 只读增量使用公开 `baseline` 索引本工作页内存中的原 options、binding 及模式/控制代次，底座派发原 `semantic_snapshot` 的 baselineId；模型不能提供原生基线或绑定。仅当前首个有界片段可更新，续页及局部 AX 不提供增量基线，其他操作使旧基线失效；不扩大读取范围，保留原生增量、分块、coverage 与 resync 合同。该能力不授予引用写入或脚本资格。

- 已归档源码以 `main` 为唯一长期主线。Fast-Backlink 配套适配切片及独立 Assist 产品分别组合验收；源码已归档不代表已安装或已发布，未验证的独立产品不能替换内置协作。
- 独立 Assist 的正式接收端位于 `native-extension/assist-*.mjs`；跨仓测试显式绑定该目录，不使用忽略区旧副本。观察返回的 tab/window 仅作关联，后台工作持不透明句柄；报告/查询策略由 Native 冻结，业务结果未知不能借关页或重配对重放。普通会话请求达到容量后仍保留独立有界清理通路，跨两种请求集合禁止重复 ID。
- Assist `work.snapshot` 可携带有界局部读取 options，由接收端与 Native 分别校验并沿既有 semantic_snapshot 执行；零匹配直接返回空集，不进入扩大范围和预算的目标恢复。文本按 UTF-16 单元限制；不开放原生 frame、cursor、baseline 或文档绑定，缺能力的旧接收端明确拒绝。只读续读仅接 `continuation`，Native 保存原生 cursor、原参数及 binding，每工作页一个内存句柄；末端在每次等待后核原文档与语义租约。其他操作、新读取、消费或断连后旧句柄不复活，未知不重放。resync、分块与 coverage 保留，局部 AX 不支持分页时明确返回不完整且无续读；只读增量合同见上文，引用写入另验。
- 用户已批准浏览器执行底座拆分及 Fast-Backlink 首批一键填写接入，并明确移除云端链接；批量投稿后续迁移。本批本地实现完成后仍须经过实际组合验收和发布审批。
- 本批新增当前页成品包导出：渲染后 HTML、浏览器已加载且可读的前端资源及覆盖清单；不爬全站、不还原后端或原始框架工程。复用脚本/CDP执行链，只读原页，不重新请求资源；默认清除表单当前值，离线预览禁止脚本与外部网络，保留缺失和预算限制。
- 导出不能使用 `Page.getResourceContent`：Chromium 内容加载器会重抓样式表，真实本地 HTTP 计数已复现。资源正文取内存 MHTML 中匹配顶层清单的非HTML Part；脚本取同frame默认世界已编译源码。缺件明确partial，不刷新或fetch补抓。图片保留MIME对应扩展名，未知CSS引用禁用并披露；离线HTTP预览要实测缓存样式/图片，而非只看ZIP有文件。
- 脚本收集重放完整有界事件历史及新增分页，不把第一页末游标当日志尾。Runtime/Debugger 已启用时不会重新发送全部上下文/脚本；重复导出与先读控制台须有阳性回归。仅活跃顶层默认上下文的唯一脚本可读，子会话、sourceURL、事件缺口及同URL歧义明确漏收；不通过disable重置调试器影响其他工具。
- 现有CDP通道先通过目标授权再登记缓冲，随后发送命令；Runtime.enable首批事件可能在命令响应前到达，响应后才subscribe会永久丢掉上下文。真实预enable/连续导出与同步事件夹具均覆盖该窗口。
- 导出HTML的安全边界以实际序列化再解析为准：拒绝非规范HTML根，去除非HTML命名空间子树、动态注释、非标准大小写/带命名空间属性及旧charset，UTF-8字节起始用BOM固定编码，不依赖长根属性之后的meta预扫描。清理后的head移到根首部，防止活页head位于正文时CSP被重解析到body而失效；真实离线表单用securitypolicyviolation和零导航核form-action生效。未知CSS函数/转义/注释禁用并披露，缓存CSS的import整表禁用以免预算裁剪后悬空；原始资源仍保留在私有包，不能称彻底脱敏。
- 架构与接入边界见 [浏览器执行底座](browser-core.md)。新安装不包含云端运行能力，旧安装退役仍须核在途任务并保留私有数据和回滚材料；不操作远程服务或删除云端账号。
- macOS 测试使用明确指定的私有 `TMPDIR`，浏览器保留真实 `HOME`。当前终端默认 Python 不满足项目要求；显式使用已核的 Python 3.14 和可用 Node，不依赖 Homebrew 的损坏 Node 动态库。
- 测试后台静默执行，浏览器默认无头，不弹出测试窗口或抢占用户焦点；需要可见浏览器的专项验收先说明并征求同意，不用有头结果替代无头结果。只在完成、实际阻塞或需要决定时汇报。
- 原工作树到私有临时根的相对路径过长会令维护套接字夹具失败；用正式门禁的 snapshot/inventory 在同一私有 scratch 建短源码快照、按锁文件安装依赖，并对照前后源码清单。历史云升级夹具显式设置 `BROWSER_LINK_RELEASE_HISTORY` 指向只读原仓；不修改生产地址限制或退回系统临时目录。
- 安装 CLI 的外部包只复制到本次私有快照一次，完整校验后由 plan/apply 复用该快照与清单；公开低级安装入口仍独立快照外部输入。目标复制后和激活后继续核完整集合、摘要及扩展身份，不为减少重复 IO 省略末端复核；安装套件按整个 runner 的 150 秒累计期限验收。
- 执行测试临时设 `ready=False` 时，持所属 Assist 实例的既有锁覆盖 `patch.dict` 进入、真实快捷任务请求和恢复；后台 view 会替换 suggestions 字典，浅快照恢复可能丢失新插入的显式任务。用受控刷新线程证明任务身份保留且放锁后刷新继续，不改生产任务合同或增加等待期限。
- 源码清单排除 Ruff 缓存并有行为回归；真实实现或测试在验收期间变化仍判漂移。组合验收的原页导航计数仅计算该原页精确路径/查询，不把其他独立换文档探针的重载计入原页保留断言。
- SDK、隔离安装、真实临时浏览器和个人安装分别验收，不以 import 成功代替端到端接入。
- 共享 SDK 与底层客户端按真实路径隔离加载；同时测试调用方已有同名模块及多个候选，不能只在空进程测普通 import。未知写入用原请求状态只读核对，不生成新请求补写。
- 通用 `ref_fill` 不提供工作产品的人工输入与提交锁保护；跨进程接入先前置检查还不够，必须在真正写入处核业务绑定。安全协议未接通时不把适配器或测试替身报告为一键填写迁移完成。
- 核心 `daemon.py` 与固定产品 bootstrap 分离，完整安装的客户端启动 `assist_adapter.py`；安装、打包、维护PID核对及测试清理必须同步。已存在但缺件的 `host-bin` 拒绝启动，不能从下载源码或纯核心回退，避免健康检查通过而产品路由失效。
- 跨仓配套测试按真实内容端合同连接：`revoke` 回当前绑定 epoch，不替业务产品递增；新一轮显式填写先确认旧绑定撤销，再递增 epoch 重新 bind。普通页没有业务条目时明确使用非记录身份，不把 `null` 传入要求非空字符串的 Native/content 合同。模拟 Port 回执必须与真实模块一致，不能单仓全绿掩盖协议错配。
- 产品写入结果未知时，扩展阻止换请求编号和重新绑定，Native 在派发前持久保存未知屏障；关闭、重新 attach 及宿主重启均不能清除。持久化调用遵循 `persist_lock → state_lock`，不得持有状态锁等待快照 IO；安装回执已证实注入时先保存精确通道，再检查暂停/租约，以便撤销收尾。
- MV3 service worker 的产品模块使用静态 import，实例可以延迟构造；Node 支持的动态 import 不证明扩展 worker 支持。新增后台入口须通过真实后台路由与临时浏览器首次调用验证，不能只在扩展页面导入模块。
- 诊断查询及归属 lookup 仅连接已运行服务，不启动 daemon、不刷新同 owner 任何任务的活动与自动关闭期限。执行世界、框架和 debugger 准备失败只有明确未发送业务求值才投影 `runtime_preparation_failed`；已发送的求值即使抛 `SyntaxError` 也保留 unknown，最终工具出口不得改写该事实。
- 产品原页选取即冻结浏览器返回的 documentId，审批前后与首次权威注入均精确限定该文档；相同 URL 重新加载不承接旧业务意图。普通原页接管保持既有合同，新增文档证明只由可信产品选页入口请求，不能由业务产品或模型提供。
