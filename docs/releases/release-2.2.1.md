# Fast-browser-link 2.2.1

日期：2026-10-21。是否已发布及安装包，以本仓库对应的 GitHub Release 为准。

## 改动

- 修复建页异常丢成 EOF、读取/截图未知状态被覆盖、失败核实误解冻及迟到下载漏归属；不自动重放未知写入。
- 收口 Assist 侧栏/悬浮层，修复样式泄漏导致独立结果文档无法滚动；日志区分主动退出、完成状态和实际推理耗时。
- 长文保留预算内摘要、片段与原续读游标；等待容量在入队前准入，派发前再次校验绝对截止时间。
- 完善云连接退避、表格/ARIA/同名控件语义，以及桥接、socket、临时目录隔离回归。

## 安装

macOS、Python 3.11+，Chrome 或 Edge。独立模式下载 `fast-browser-link-2.2.1.zip`；首次安装按包内说明执行，已有安装用 `./install.sh --upgrade`，保留 `.fast-browser-link/plugin-data`。Hermes 集成使用 `fast-browser-link-hermes-2.2.1.zip`，已有安装同样执行 `./install.sh --upgrade`。升级前遵循安装器维护门禁，完成后重载原扩展并重新加载插件运行时；文件已更新与活跃版本已切换须分别核实。
