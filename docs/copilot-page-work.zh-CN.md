# 页面标注、工作篮与执行分级

“页面内标注”默认开启，可在设置 › 界面选择简洁或完整密度。识别可见关键词/域名/URL 列、工具画像别名/选择器，以及搜索词、结果和相关问题；不读输入框值、隐藏内容或编辑器。覆盖层使用 closed shadow root，不包装/改写原页面节点，跟随滚动、虚拟行复用，拒绝过期回执。每页最多300个对象；超出后只标可视对象。Hermes/Fast-browser-link 归属工作页在采集和请求两层排除。

标签只消费已有结果、本机缓存、已验证词池回执；真实零值显示为0，缺值保持未知。小站只显示已有结果/本机规则给出的标记，不内置业务阈值。可选 pool.lookup 仅在显式声明零成本、本地、只读时自动读取，并受禁止联网/越出工作目录写入的沙箱及短截止限制；未分级的旧查询命令不会因悬停启动。识别页面不会自动调用指标或权重来源。

通过页面＋、划词窗、结果行勾选、已确认导出的整表/所选列加入工作篮。`basket.json` 在选中运行时的协作数据目录私有持久化，导出表引用重启后可读。按类型/归一化对象/列选择去重；可分组、删选中、清空。数量/字节预算在写入前校验，不静默截断用户篮子。

批量查词定档、拆长尾、热度、竞品与存池都先显示预估：所选对象、一张结果任务、固定来源、批次和调用上限、模型调用、粗略 token、已知耗时或明确未知/调用超时预算（不含排队与人工处理）。估计不是报价、完成期限或实际回执。单对象适配器逐项，批量适配器遵循声明上限；精确指标至多100词/批，趋势至多5词/批。后续域名调用仅能估上限，不暗换 agent 后备或其他来源。篮子、绑定或有效期变化需重估。

确认后后台执行；对外/不可逆风险还需独立第二次确认回执。最多合并一次模型判断，档位由本机判断器给出；缺判断器、指标或权重不编造档位。热度保留范围和原始曲线，卡片预览末尾点及范围，完整序列在文件中。一张合并卡片和逐批日志写来源、成功返回数、跳过输入和失败数。不可用/结果未知不重放。停止阻止后续批次；已发送写入可能仍需回读。部分数据保留，再执行需重新估算。

新批量任务的活动/需核对状态同时进入升级空闲门禁；活动或中断的对外任务阻止升级，不能删除账本/标记来绕过未知结果。

复制与 Excel/CSV 导出也是本机确认动作。导出复用配置过的 TableStore 目录，CSV 防公式注入、XLSX 按文本/数值保存，不接受批量请求传路径；过大剪贴板内容转为提示导出。旧结果卡批量/存池、表格列批量入口也走预估页。确认后的旧本机存池命令可在模型未启用时执行，但成员标签必须有实际回执。

## 扩展包契约

模板、工作流、步骤与绑定可声明 `risk: "zero" | "metered" | "external"`；未声明默认 **metered（消耗额度）**。未知成本和 agent/模型路径至少是消耗额度；`external: true`、`writes_outside_export_root: true` 提升为对外风险。风险由 daemon 判定，不采纳网页/推理输出提供的风险标记。

自动读取的绑定还需 `cost: zero/free/local`、`read_only: true`；命令需 `local_only: true`，运行时禁止网络及越出生成工作目录的写入，沙箱不可用则不执行。浏览器需 `public: true`、`requires_login: false`，不得附命令查询规划器。MCP/agent 后备不会自动调用。仅写 `risk: zero` 不能放行付费、未知或需登录来源。

零成本且无模型的扩展工作流须显式 `risk: zero`、`judgment: false`，所有步骤也声明零风险且只用合格读取器/本机转换；模型步骤或未声明步骤不能自动执行。内置 local.lookup 和有效缓存命中可自动完成；设置 › 执行模式中的开关默认开，关闭后建议保持待执行。卡片/日志标“自动”，本机或批量任务结束不会额外触发仅为完成通知的模型推理。

可用 `estimated_seconds` 提供预估；凭据、付费来源、站点与阈值仍留本机包/配置。参见[包开发](fbl-packs.zh-CN.md)。离线样稿是合成 DOM 输出，不能代替实际 Edge、扩展、账号、模型或供应商验收。
