# 弹窗与任务控制

弹窗头部圆点表示当前本地连接状态，不代表任意页面授权。确认连接后，Fast-browser-link可直接读取、点击、填写任务页并执行任务页脚本，无须逐站或逐项审批。连接授权只能在扩展自己的界面确认。任务隔离、接管、停止和密码值不回显语义保留，不新增模式选择或独立操作授权开关。

本地与云端行的ⓘ可悬停或键盘聚焦查看完整说明。离线、未知状态不能证明当前可访问；旧缓存不能证明连接或授权。确认云端配对后，只允许直接读取、点击和填写云端创建的任务页，不授权已有个人标签页。断开和重新配对仍需显式操作，不记录密码输入值。

“打开协作看板”成功打开浏览器侧栏后才关闭弹窗；协作开关与侧栏共用同一本机设置。点击云端行只展开内联配对面板，不生成码、不配对也不断开。配对、重新生成、复制与断开均需明确点击。跳转成功后关闭弹窗，其他操作保持弹窗。Esc先收起配对面板，再关闭弹窗；错误必须手动关闭。

任务控制绑定当前归属页、任务身份与代次；结果未知不会自动重发。停止回执可短暂显示，但不宣称页面仍属该任务。页面浮层停止须在三秒内二次点击，继续验证原有宿主回执。closed shadow、预浮层首帧、截图透明期间继续拦截输入等语义不变。确认停止仍走既有任务清理并卸载阻挡浮层；显示组件支持终态样稿，不能为保留“已停止”提示而让撤销任务的拦截层继续存活。

日志只使用宿主已有的脱敏动作摘要，不读输入值或原始异常。默认最近八步，可展开/复制宿主提供的最多100条；上滚暂停跟随，“回到最新”恢复。最小化/折叠偏好按任务代次保存在扩展本机存储，不写网站存储。最小化只改变显示，不改变拦截或权限。
