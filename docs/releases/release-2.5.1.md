# Fast-browser-link 2.5.1

发布日期：2026-10-31。macOS 稳定版；Chrome 和 Edge 保持同一固定扩展 ID。

## 改动

- 任务创建可唤醒曾连接的离线 Chrome/Edge 实例：macOS 后台启动对应应用，最多等待 12 秒同一实例重连。列表和诊断不启动浏览器，未知实例与重连失败不创建任务，也不自动切换目标；原有浏览器授权仍需完成。
- 已终结、清理成功且没有未决操作或标签租约的旧任务，在默认七天后移入私有压缩 SQLite 归档。近期任务继续由原有 JSON 账本服务浏览器执行；过期不会把未知操作改成成功。
- 归档采用先提交数据库、后缩减热账本的可恢复顺序；补齐独立版与 Hermes 包中的 Native host 模块闭包。
- 现有历史备份不自动删除，归档记录可按任务 ID 读回。无需安装或运行独立数据库服务。

## 安装

独立模式下载 `fast-browser-link-2.5.1.zip`，解压后对已有安装运行 `./install.sh --upgrade`；升级保留 `.fast-browser-link/plugin-data`。Hermes integration 使用单独的 `fast-browser-link-hermes-2.5.1.zip`，其已有安装也使用 `./install.sh --upgrade`。升级前先运行 `--dry-run`，处理仍在执行或结果未知的任务。更新后重载 Chrome/Edge 扩展，并重新加载或重启 Hermes 插件运行时。

## 验证范围

本版完整离线门禁通过：Node 1,165/1,165，原生桥接 152/152；固定 Hermes 集成门禁包含 146 个基线、2 个补充及 55 个审阅步骤。格式、运行时、文档与公开源码检查通过。离线启动覆盖旧账本恢复、同实例回连、并发单次启动、启动失败、超时和无效输入；未关闭个人浏览器来模拟真实离线。用当前账本的临时副本试迁移：1,546 条任务归档后，热账本由 35.0 MiB 降至 8.2 MiB，归档文件为 7.5 MiB，迁移约一秒；此试验未改动本机真实账本。正式包、GitHub 门禁及本机升级另行读回。真实账号、第三方网页任务及其他平台不属于此次验收。
