# 协作模式（2.2.0 本地候选）

首次引导只读检测本机协作运行环境，支持 Hermes 与 Codex，后者使用官方 app-server，详见下文。用户选择默认 Agent 并明确开始后，后台执行安装、专用配置、浏览器工具绑定及 ACP 初始化连通检查。设置 → 协作 Agent 可重新打开引导；切换默认 Agent 前需要关闭协作并等待任务结束。配置检查完成不会自动启动协作，运行状态也不会因此提前显示已连接；状态名称来自所选 Agent，只有已开启、已就绪且连接成功后才显示协作中。

全新缺失的 Hermes 引擎，在用户点击安装后使用官方 HTTPS 非交互稳定版安装器；已有引擎目录、凭据或默认配置会被保留，引擎不可用时需人工修复。缺少模型授权会提示在本机执行 `hermes model`，扩展不采集凭据。配置 worker 不发送模型提示词，也不接管既有未受管专用配置。

识别到的页面表格作为本地建议卡片展示，与其他建议合计最多十条，不自动在顶部展示导出控件或弹出确认窗口。点击“执行”后打开表格导出弹窗，选择保存动作才进入原有的一次性表格确认流程。保存回执在结果中只显示一次，可从详情重新进入文件、选列和工作篮操作。

“当前目标”区域在协作推进时显示动态轨道，并适配系统减少动态效果设置。右侧“调整方向”打开输入弹窗，保存成功后关闭，失败保留草稿。“思考日志”通过二级弹窗展示已有依据、约束、待确认事项与用户反馈；用户方向优先于推测目标。

设置页的本机能力声明统一使用共享表单样式。“默认导出目录”支持 macOS 原生目录选择和恢复默认；选择成功后才保存，取消保留原目录。目录选择在后台执行，关闭侧栏会取消。设置页不再显示页面表格识别，表格确认和进行中任务保留在工作视图。“关于”集中展示版本、用量和连接状态，点击日志目录打开当前运行目录下的日志文件夹。目录操作需要匹配更新后的扩展与本机宿主。

协作模式读取普通网页的有界语义快照与最近30步操作，侧栏展示建议、任务进度和结果。关闭时注销采集，取消本次任务并回收协作进程。未安装、同步或发布当前候选；验收记录见本机保留的历史实施报告。

## 开启前设置

打开侧栏先读取统一 Fast-copilot profile 的模型清单（分析和执行共用一次发现），缓存24小时；“刷新模型”强制重取。发现只做 ACP initialize/session/new，不发送 prompt，不消耗模型 token；Hermes 仍可能访问提供商模型目录。失败时可手动填写合法 `provider:model`（含 `custom:name:model`）。不接受空格、命令选项或 shell 符号；空值使用对应 profile 默认。

主界面只显示状态、今日/本次用量和建议/进行中/结果。齿轮打开设置二级页，分为界面、执行模式、高级（默认折叠）和本机能力；日志图标打开同一侧栏内的实时日志页，返回不创建新标签。首次开启直接保存均衡默认值并显示可关闭提示。字段修改自动保存，旁边短暂显示✓；下一次推理/执行生效，进行中的任务保留启动时的配置。预设按模型名挑选，不是实时价格排序；没有匹配项时沿用profile默认。

设置只存在 daemon 的本机 `copilot/config.json`，不存浏览器、不修改 Hermes 全局或 profile 默认模型。模型通过 ACP session/set_model 或独立 CLI `-m` 传递。卡片分别标注 ACP 会话模型、oneshot 启动回报或缓存来源；后者不是提供商逐请求路由的独立证明。今日/会话/任务分别列输入、缓存读、输出，并按模型汇总；旧账本无法归属的量标为历史/未归属。

## 初始化与升级

连接 Agent 统一命名为 **Fast-copilot**；Hermes 的 profile 标识按其规则使用小写 `fast-copilot`。新安装只创建这一个 profile。升级时沿用带归属标记的旧 `copilot`（其次 `copilot-exec`）配置参数，保留模型、提供商和较新配置版本；旧目录与会话不自动删除。完成本机同步和重新设置后，再备份归档旧 profile。

由用户执行预览，确认后加 `--apply`：

```sh
bash scripts/setup-copilot-profile.sh
bash scripts/setup-copilot-profile.sh --apply
```

默认 `gpt-5.6-luna / openai-codex`，可传 model/provider。脚本只新建或升级摘要仍匹配的自有受管文件；未知 profile、用户修改、插件引用变化、模型/provider不匹配均拒绝。现有模型不同需传原模型/provider。升级补关闭自动标题/后台review/记忆、manual审批等项；统一 profile 的 ACP 和 CLI 默认工具均为空；oneshot 通过模板的 `-t` 与 `--max-turns` 显式启用工具和轮数。终端永久放行清单为空，没有 yolo。确定性取数已由 daemon 负责，判读无需授权危险命令。认证不复制，沿用 Hermes 的共享规则。

真实 config 位于 `<运行时根>/plugin-data/fast-browser-link-native/copilot/`。独立根为 `~/.fast-browser-link`，Hermes 适配器使用既有 shared-root。仓库示例为 `native-bridge/copilot-config.example.json`。安装/同步只补不存在的配置和模板，已有文件需用户合并本轮字段/schema/fetch步骤，本轮未实际安装或同步。

## 执行与已知限制

默认 `exec_transport=acp`：协作开启时建立常驻执行连接，每个SEO判读任务新建独立会话；先核对零工具，再仅发一个模型判读 prompt。工具检查 `/tools` 和清理 `/reset` 是本地命令，不调用模型。结果 JSON 由 daemon 校验并私有落盘，模型不需要文件或终端权限。同进程多会话并发，上限 max_parallel；停止发对应 session/cancel。传输崩溃只重启一次，失败任务不自动重放；再失败显示中文诊断，需要检查后重新连接。

**当前 Hermes ACP 不支持每会话工具/轮数上限配置，也没有逐会话关闭接口。** 通用任务在 ACP 路径会明确拒绝，请选择 `oneshot` 后备完整执行；不会悄悄放开工具。任务完成用 `/reset` 清空历史并停止客户端使用该会话，Hermes 仍保留会话对象/记录到进程关闭，这不等同于真正逐会话结束。本轮不能宣称完整实现了这两项上游能力。

`exec_transport=oneshot` 保留独立 `hermes chat`。通用任务继续完整工具执行；SEO取数后使用 `-t none --max-turns 1` 输出JSON，不再工具循环。显式启用的关键词取数后备才用浏览器，受后备上限和模板/全局上限共同限制。常规工具上限取小，模板基础：关键词15、长尾12、竞品15、SERP6；倍率仅作用于工具路径，SEO纯判读固定单轮。Hermes 可能额外收尾/重试，真实API次数需账单核对。

新任务附本次已完成工作的短清单，总长≤500 UTF-8字节；每个任务始终新会话，不把历史任务上下文串成一条长会话。

## SEO 取数接口

模板 `fetch` 声明 script、params_schema、output_schema、timeout。`fetch_commands` 将脚本名映射为本机命令 argv；命令从 stdin 读参数JSON，向 stdout 写符合模板schema的JSON，stderr不送模型。无 shell 拼接。相对可执行文件可由 `fetch_dir` 指定本机脚本目录；私有工具/凭据不要放进公开模板。

- 长尾：内置 Google Suggest 英文接口，种子+26字母+5问句前缀，最多100个去重候选。HTTP无模型token；部分失败会注明，不能将该来源当作地区精确搜索量。
- 关键词：`keyword_metrics` 提供词/量/KD/CPC；`serp_top10` 提供前十URL/标题。由本机配置JSON接口包装现有工具；没有配置明确标缺数据，不能把 不同来源的 KD 冒充example-seo-tool KD。
- 竞品：`competitor_keywords` 提供流量词与 pages，未配置标缺数据。
- SERP拆解：只用与对象URL对应的现有采集快照，不额外取数。
- 存词池：本地CSV/配置的 pool_command，不调用模型。已有关键词/竞品7天缓存命中也不调用模型。

查看各模板 output_schema 配置私有适配命令；例如关键词接口输出 `{"keywords":[{"keyword":"example","vol":100,"kd":12,"cpc":1.2}],"source":"本机查实来源"}`，SERP接口输出 `{"results":[{"url":"https://example.test/","title":"样例"}],"source":"本机查实来源"}`。只接受查实数字，缺失字段省略。命令成功并不代表数据来自正确市场，需适配器保留来源语义。

缺源/超时/错误格式都会进入 `missing_data` 和结果卡。关键词模板的 `fetch_fallback.enabled` 默认false；用户显式启用后仅用受限oneshot补缺，默认最多3轮。不会静默回退到无限工具调用。

## 采集、用量与隐私

默认上下文阈值6000，达到阈值请求≤160字摘要后新会话接续；不是单次请求硬上限。每日、本次与任务的输入/缓存读/输出按模型统计，仅作信息展示，无每日限额或加权暂停。旧配置的daily_token_budget/cache_weight读取时忽略，下次保存移除。缺少可靠usage时注明估算。3分钟空闲暂停、30分钟自动关闭保持。

实时lease/task及持久化workspace归属的工作页均不采集。导航等待DOM静默800ms，最长5秒；晚到表格补发，相同快照合并。语义快照≤3KB，不读输入值、cookie、存储或整页DOM；PDF和特殊协议不采集。

悬浮球位置全局保存在扩展local storage，右键/长按隐藏，侧栏打开时不显示迷你列表。报告与模型缓存保存在本机；日志保留7天，勿公开个人数据。

## R7 结构化结果与后台表格

结果统一包含 verdict（≤30字结论）、level、最多3项metrics、missing、process、最多2个next；各模板有独立主体和decision_schema。模型只输出判断，量/KD/CPC/排名由daemon从取数源合并，非法模型字段仍记已发生用量后拒绝。旧缓存尽量转换，无法转换时通用卡提示核对；不会将原始JSON倒进侧栏。

结果默认折叠；长尾按组切换、前5条、组头全选，竞品优先可做词、前10条并可排序。勾选后批量查词只建一个执行，存池走本地；上限1000词，超出明确拒绝，不截断。补取指标只重跑keyword_metrics批量接口，保留原判断，不发模型请求。缺量/KD整列隐藏并注明原因。✓池仅根据可核实的accepted_keywords回执，未回执不凭退出0假定已入池；written未知用null与missing说明。

新结果按完成时间排序，同对象同动作的显式新结果替换旧记录，旧记录/报告进历史；子任务挂父结果，20个根结果后折叠，更早内容可展开。完整表在后台新标签页打开扩展内部页，可排序/筛选并由daemon导出CSV；不会自动激活标签。

表格条支持原生table、ARIA grid/table/treegrid、data-ui-name和重复行/表头div表格。只读取已渲染且未隐藏的文本；控件、编辑区、隐藏字段不读，链接地址单独保留。自动采集只把列名/行数摘要送推理；手动“识别当前表格”及导出可在模型未开启时使用，操作本身0模型token。用户主动选词仍可成为操作上下文。

Excel/CSV保存到table_export_dir（默认~/Downloads/fast-browser-link/），不走浏览器下载框。XLSX由stdlib ZIP/XML生成，原文为文字、数值另列、链接另列；CSV UTF-8 BOM，公式样式文本作文字保护。复制TSV提供原表可见文字。打开文件/目录只接受本次导出的文件ID，不接受任意路径。

“保存全部”只在独立“Hermes 协作·”工作页运行，经原有workspace-only授权/租约安装，不借用用户标签；保持原普通/无痕上下文。URL分页、按钮分页、无限/虚拟滚动逐批合并、整行去重。生产按钮点击通过Executor语义引用，滚动通过受控Executor/CDP静态操作，保留原权限/遮挡检查。无法核实的分页目标、登录/验证码/额度、结构变化、焦点或归属变化立即停止并保存部分；不点站点导出。

默认1.5–3秒随机页间隔，table_max_pages默认50，可配1–200；预计超过配置上限要在侧栏再次确认，未知页数触顶仅保存部分。虚拟滚动按“批次”计，不假称页数。后台节流通过worker轮询加载/稳定状态应对，单次脚本10秒硬超时，不激活页面、不禁用浏览器节流；不能保证所有站点隐藏渲染都可运行。

静默能力由daemon短期令牌下发Hermes子进程，再经正常BridgeClient标记任务；每次开启轮换，不持久化令牌。静默任务强制separate工作窗口，禁止CDP显式激活/新建非受管target/窗口调整；输入不走激活队列，用户移走或正在前台查看工作页则拒绝动作。审批不弹系统通知，结果/进度只在侧栏，球显示进行中/新结果及表格提示。显式用户点击“打开文件”仍交系统默认程序处理。

本轮未安装、同步、发布或改真实配置；PNG与真实Edge验收仍待本机。三种表格本地页：`docs/growth/assets/r7-table-fixture.html`，可从仓库根运行普通HTTP静态服务器后访问（由用户执行），详见报告。R6b通用任务ACP/真正逐会话关闭的上游限制保持。

划词任务、趋势及本机适配扩展点参见[协作扩展包](copilot-packages.zh-CN.md)。

工具记忆、能力绑定、只读体检和组合编排见[能力说明](copilot-capabilities.zh-CN.md)。

## 实时日志

日志按采集、推理、执行、系统分类，包含大小、token（含估算标记）、耗时、建议变动计数、取数器/页码/脚本阶段、能力体检和配置变更；不保存输入值、Cookie、认证头、页面全文或命令参数。只记录固定摘要、统计和来源标识；失败保留固定错误码而非任意异常正文。

日志每200ms合批推送，只在日志页渲染固定行高的视口窗口；详情单独展开，避免JSON改变行高。最多2000条，支持类型/错误/搜索筛选、暂停滚动、回到最新、当前浏览器当天清空及全部JSONL复制/导出。文件位于协作数据目录logs/YYYY-MM-DD.events.jsonl，0600权限，保留7天；重开面板可读回当天记录。离线连接事件先标作本地临时记录，恢复后提交与读回，不冒充已持久化。

协作看板默认名为“Hermes协作看板”（英文 Hermes Copilot），可在设置的“界面”修改；品牌仍是 Fast-browser-link。一级视图仅保留连接、建议/进行中/折叠结果、最近3条日志和今日用量；执行、表格导出和本机能力在二级设置中。弹窗的看板按钮仅在协作开启时显示。

提取表格先在原页面与侧栏同步确认；页面装饰层使用 closed shadow root，不改表格或锁输入。确认前不导出或开启多页工作页；Esc、取消和目标移除会清理高亮，页面或数据改变时拒绝旧凭据。确认多页收集后才打开同一地址的后台工作页；上限仍为200页。

“本机 Hermes”仅检查当前ACP就绪、执行profile配置文件与可执行程序是否存在，以及最近调用结果。`execution_startable` 是结构检查，不代表实际启动或模型可用性验证；读取状态不启动模型、不消耗token；启动失败后的“重试”会重新启动协作会话。灰色可能是协作尚未开启，开启协作仍会按既有流程启动会话。名称和导出设置保存到本扩展实例的协作配置，不修改Hermes配置。


## 受管模板升级与启动恢复

安装、同步和初始化共用 `copilot_setup.py`：在实例的 `copilot/managed-templates.json` 记录 `version: 1` 与 `templates` 映射，键为模板文件名；每项有内容版本 `version: "sha256:<摘要前12位>"` 和完整 `sha256`。未改过的模板随新版替换；缺失模板及新增模板自动补齐，既有 config 不覆盖。

用户修改过或来源不明的模板保留原文件，新版写到 `templates/<name>.json.new`，清单记 `pending_version`、`pending_sha256`；设置 › 本机能力显示“有模板需要合并”。手动审阅合并后再次初始化：若已采用新版，将清除未修改的候选副本并登记新版；自定义合并内容仍视为用户修改。

无清单的旧安装只在原始文件 SHA-256 匹配 `native-bridge/copilot-templates/managed-history.json` 的历史摘要或当前新版时自动接管。历史表仅含文件名与摘要，初始记录来自 Git 中的真实受管版本；维护时从每个曾交付版本执行 `git show <commit>:<template-path>`，对输出原始字节计算 SHA-256，按文件名追加去重，保留旧值。不得对个人模板生成历史条目，也不得仅按“缺少某字段”猜测未修改。

加载时按动作类型补缺失的 `decision_schema`；无法补齐的模板单独禁用，从推理合同和建议中排除并记录一次错误，不阻断其余模板的会话。设置 › 本机能力显示跳过项。启动失败显示固定中文原因；日志详情保留错误码和异常类型，不记录任意异常正文或凭据。

浏览器后台在启动失败后按 5、15、60 秒最多自动重试三次，随后保留“出错 · 重试”。启动成功就绪或用户手动开关重置计数；进程恢复失败的退避预算需一次有效推理成功才清零；关闭协作取消等待。面板重绘或重开不重置后台计数；后台销毁后不恢复遗留定时器。重试只启动新的协作会话，不重放任务。Native 浏览器桥的原有重连独立保留。

能力体检按全部标准能力计数，而非已探测绑定数：任一可用绑定使该能力计入“可用”；否则有待登录/浏览器/路由确认的绑定计入“需登录/待浏览器确认”；其余计入“未绑定”（包含没有可用绑定）。日志详情提供逐能力分类，三个计数之和等于能力总数。


## 推理诊断与进程恢复

推理错误区分 `model_output_invalid`、`acp_disconnected`、`acp_timeout`、`acp_process_exited` 和 `internal_error`，详情包含固定字段/校验码、异常类型及退出码。首次和第二次推理失败保留已有建议、显示原因提示；连续三次失败才显示错误状态，成功后清零。超长标题/理由截断并加省略号，建议最多八条，缺 id 由宿主生成，未知字段丢弃；不可用动作或不符合参数合同的行跳过，不扩大权限。规范化只记 info 日志，不弹错误。

推理 ACP、执行 ACP 及 oneshot 执行的 stderr 都在进程运行时持续读取，经保守模式脱敏后写入 `copilot/logs/YYYY-MM-DD.hermes-stderr.log`：每文件最多 2 MiB，保留一个同日 `.log.1` 轮转副本，保留七天，文件权限 0600。凭据字段所在行、已知 token 前缀、长不透明串、URL 与个人目录路径会被屏蔽；不记录 stdout 模型原始结果。退出事件包含退出码及最后二十行脱敏摘要。日志详情显示分类信息；断开事件区分用户关闭、空闲关闭、服务关闭、进程退出与传输错误。

每次协作开启期间，意外推理断线/进程退出自动恢复一次：重新验证零工具 profile，用已有摘要、完成记录与建议状态开启新推理会话，并补发当前页面增量。执行进程与进行中的任务不因此重放。恢复失败或再次退出后，转入现有 5/15/60 秒、最多三次的前端启动退避，最终停在可手动重试状态；此时短暂就绪不会清零重试次数，需一次有效推理成功或手动开关复位。

受管 profile 生成器已核对 Hermes 配置源码，生成或摘要验证后升级 `fast-copilot` 时写入 `_config_version: 50`；不降低更高版本，不改模型/供应商，不覆盖用户改过的 profile，也不运行 Hermes 的全局迁移。其余默认配置由 Hermes 读取时合并。源码更新本身不修改已安装 profile。


## 判读、部分结果与建议稳定性

ACP 单轮判读使用零工具的 `inference_profile`（默认 `fast-copilot`），通过 `session/set_model` 使用明确选择的执行模型；未选模型时使用该零工具 profile 默认模型。仍核对 `/tools`，含工具时拒绝判读，不能仅靠提示词约束。需要工具的 oneshot 同样使用 `fast-copilot`，通过启动参数限制工具和轮数。源码更新不会修改用户 Hermes profile。

执行失败也保存结果与报告：`tasks/failed-<id>/result.json` 包含失败分类、脱敏消息及已取到的原始数据；卡片列明“缺判断”，不补造档位，重试会清除旧的失败呈现再执行。工作流缺失能力时保存“跳过（未绑定能力）”步骤，继续后续步骤；有数据时尝试一次判断。结果卡和日志区分完成、部分完成（缺项数）、失败，API 用 `completion_status` 提供区分，保留既有终态分组。候选截断显示去重后数量与截断数，完整上游步骤仍留在本机。

无操作且语义快照不变的采集在本地丢弃；同秒重复事件合并，空增量不会调用模型。新模型建议至少保留30秒，并要求连续两次未再出现才撤下；页面切换可解除旧上下文的保留期。悬停、键盘焦点/展开期间卡片保留，悬停/展开同时通知宿主保留建议，避免点击已失效对象；释放后淡出，侧栏关闭会解除保留。

执行日志显示步骤、能力、工具及已返回的条数/耗时，同类连续事件折叠计数。stderr 过滤 INFO 噪声，保留警告、错误及非 INFO 诊断。推理超过5秒标为慢请求，属于信息事件。上下文优先采用 ACP `usage_update.used` 的当前上下文压力；缺省估算按增量输入和输出计算，不再累加含缓存读的计费用量；阈值仍6000。

表格采集支持原生/ARIA、分离表头与表体、虚拟行、开放 Shadow DOM 与可读同源 iframe；只识别当前可见行，不读取控件值。工具画像的页面可提供 `table_selectors` CSS 数组，`columns` 中的表头别名也参与识别，例如：

```json
{"table_selectors":[".keyword-results"],"columns":{"keyword":["Keyword","搜索词"],"kd":["KD","Difficulty"]}}
```

跨域 iframe 和封闭 Shadow DOM 不读取；嵌套上下文的分页不自动执行，识别结果标记可能不完整，保留原有保存前确认与工作页归属检查。

## 持续工作理解与轻量纠偏

侧栏展示“当前理解（推测）”、下一步和可展开的依据/约束/待确认项。模型逐步更新工作假设，用户无需先填写目标；“修正方向”是一句独立的用户要求，不由模型覆盖，也不授予额外执行权限。相关页面切换保留工作理解；推理会话滚动和进程重连会带回工作状态、纠偏和最近结果摘要。工作理解仅保存在当前 daemon 的实例状态中，daemon 重启后不恢复。

“稍后”和“方向不对”反馈只作用于本次工作，阻止同一动作立即重复，不冒充任务完成；仍可通过划词等显式入口重新派发。“开始新工作”清空当前理解、方向和纠偏，并在下一次推理建立干净会话；已有任务和结果继续留在看板，旧任务的晚到结果不进入新工作的上下文。推理期间修正方向会使旧回包失效。

采集等待页面稳定时保留最多30项有序操作，复制与滚动参与增量；滚动附带可见章节标题。同页相同批次在1秒内去重，不再按文字跨页屏蔽划词。表格页保留表外正文和标题，表格仍只自动发送列名/行数摘要，输入值和隐藏内容不采集。

任务终态回流最近6项精简结果：结论、最多3项要点/指标/来源/过程、最多5项缺失与完成状态。完整报告与原始表格不回灌推理，模型投影沿用脱敏；自动任务不会仅为完成通知额外触发模型。执行权限、付费来源确认和工作页隔离保持既有规则。


## 使用 Codex

在“设置 → 协作 Agent”中选择 **Codex**，点击“检查并连接”。Assist 支持 CLI **0.162.1 及以上**；过低或无法识别的版本会在启动 app-server 前拒绝。Assist 只启动自己持有的 stdio 进程，不附着用户已有 Codex 会话。请按[官方安装说明](https://developers.openai.com/codex/cli)，自行在终端执行 `npm install -g @openai/codex`，然后执行 `codex login`。扩展仅显示命令，不自动安装或登录。连接检查读取版本与认证状态、完成握手，不发送模型 prompt，不读取凭据文件，也不修改用户 Codex 配置。

Codex 推理为**受限模式（只读沙箱、无执行环境、宿主审计）**，回执为 `restricted_audited`。线程使用空的 0700 私有临时目录、`approvalPolicy: never`、空执行环境和空动态工具，并通过进程/线程配置覆盖关闭已知 shell、搜索、MCP、插件、hooks 与 skills 来源。宿主核对实际沙箱和审批回执；发现工具事件或未知 item 类型就中断、丢弃本轮输出并计入推理失败。审批和动态工具请求均拒绝。Hermes 继续使用已有“已核实零工具”检查；Codex 审计不能证明所有工具及副作用都在发生前被阻止。

执行任务（包括 `general.task`）各自持有一个 app-server 进程和一个临时线程，要求 `workspace-write`、命令网络关闭、仅任务目录可写，显式排除 `/tmp` 和环境临时目录根；策略回执不符即拒绝。浏览器工具从模板投影为窄动作；真实 owner 和授权留在 daemon，每次核对 instance、任务、generation、工作页及有效租约，原子扣减动作额度。取消时先撤销授权、拒绝挂起调用并 interrupt，再清理工作页、结束自有进程。`outcome_unknown` 不重放；浏览器清理独立记录，未知不能算成功。

模型通过 `model/list` 分页获取，目录缓存按 Agent、版本、provider 分隔，逐线程/轮选择。用量分为输入、缓存读、输出；缺失或不一致时明确标估算。切换 Agent 必须处于空闲状态，会清空旧模型选择，不迁移会话或授权。宿主发起的轮数、浏览器动作和总耗时均有界，**公开接口无法硬限制同一轮内部的模型请求次数**。真实 OS 沙箱、账号和模型可用性、浏览器授权撤销及清理仍需在目标机器验收；离线 fixture 只能证明解析和调度。协议见[官方 app-server 文档](https://developers.openai.com/codex/app-server)。
