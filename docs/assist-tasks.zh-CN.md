# 通用任务与协作推荐

本地候选提供通用任务工作台和统一推荐链路。任务围绕用户明确收集的材料运行，复用现有任务队列、Agent 适配器、结果视图和插件能力绑定；不会因为浏览、停留或安装插件就自动执行任务。

## 开始使用

1. 在侧栏“建议”区选择任务卡，进入该任务的材料与参数配置。可以读取当前页、选区、页面表格或可见 Canvas，也可粘贴文字、CSV/TSV，或导入 PNG。
2. 勾选本次要使用的材料。页面读取和 Canvas 只覆盖已收集范围；导航不会删除已收集快照。表格比较与主键关联须恰好选择两张表。
3. 选择任务并设置参数。清洗、统计等本地处理不需要连接模型；页面分析、学习和研究任务需要协作 Agent 已就绪。
4. 需要自然语言表格规则时，先描述要求，再生成并审阅规则预览。此操作调用受限模型，只生成选项；点击执行后才处理表格。
5. 在进行中和结果中查看回执。结果可以继续加入材料，重新筛选、比较、讲解或生成练习。

材料正文默认保留在本次宿主进程的内存中；显式执行的结果与文件保存在本机私有任务目录。用户选择保存的练习记录可在工作台按需读取。关闭工作记忆后不继续保存这些记录，清空记录会删除对应学习文件与任务效果记忆。

顶部不再单列“页面工具”。识别表格、多页采集和页面标注作为当前普通网页的建议卡出现；工作篮有内容时提供工作篮卡。识别表格后由具体表格卡接替通用识别卡。表格卡仍先打开原有范围、格式和分页确认流程。未开启协作时也可使用本机卡；切换到受限页面会清除旧页面入口。打开侧栏只同步当前标签的位置元数据，不自动读取正文。

## 设置与完成详情

设置分为通用、模型与执行、表格与导出、记忆与隐私、插件与高级、关于六类，每次只挂载当前类别。Tab 支持左右方向键、Home/End；窄屏可横向滚动。跨类别及后台刷新均保留未保存草稿，点击底部“保存更改”后才应用；“重置更改”恢复已保存值，重置或离开设置前提示确认。保存失败时保留未成功的更改，重试不会丢失保存期间的新编辑。

Tab 栏旁的“展开所有菜单”可将六个分类展开为两列；“收起菜单”恢复横向菜单，并将当前分类滚回可见范围。展开只改变菜单布局，不挂载其他类别内容，也不改变草稿或当前内容滚动位置。

完成详情保留任务名称、状态和已记录耗时，默认显示结果 Tab。已有结果合同沿用原有表格、趋势、来源与产物交互；未知内容按类型显示分页表格、懒展开 JSON、Markdown、图片或原始文本。大表先提供分页预览，完整交互视图按需展开，原始记录及顺序保持不变。

点击完成详情会打开浏览器前台标签页，在其中显示原生大模态框，不再创建固定小尺寸窗口。桌面约为 90vw × 85vh，上限 1440px × 1040px，顶部信息和分页保留，内容独立滚动；窄屏接近可用视口。支持关闭按钮、点击遮罩和 ESC，关闭前播放短过渡并关闭该详情标签页；Tab / Shift+Tab 在可见控件间循环。减少动态效果偏好下取消过渡等待。后台打开完整结果的既有入口保持后台打开。

预览页采用紧凑任务头、单条结果/日志工具栏和文档正文布局。任务上下文移入可展开的“任务信息”，点击外部或切换分页时收起。长报告按实际章节生成目录，桌面置于右侧，窄屏折叠在正文之前；点击目录可定位并聚焦章节。表格、图表、图片和 JSON 使用宽视图，不占用目录列。来源核对提示与段落引用仍保留，未核对状态不会转换为已验证状态。

日志 Tab 首次打开才读取现有任务执行日志，按时间排列并区分信息、警告和错误。支持安全字段搜索与高亮、首尾定位、跟随控制，以及复制或下载当前筛选结果。日志仍使用原有脱敏字段投影，不增加原始参数、凭据或结果正文采集。结果和日志各自处理加载、空数据和失败重试，并保留滚动位置。

## 任务目录

| 类型 | 任务 |
| --- | --- |
| 表格处理 | 整理、筛选排序、分组统计、交叉统计、比较差异、追加合并、按主键关联、解释字段与异常 |
| 页面分析 | 摘要、围绕问题阅读、结构化提取、观点与证据、产品限制、评论问题、内容矛盾与缺项 |
| 选区 | 解释、翻译 |
| 学习 | 笔记、概念与先修知识、自测题、复习卡、答案讲解、项目练习 |
| 多材料研究 | 比较、综合证据、冲突与缺项 |
| 信息整理 | 行动清单、教程步骤、规格表、版本变化、提纲与草稿、链接去重分类 |
| 表单辅助 | 填写草稿、字段要求与错误检查 |
| 图片与 Canvas | OCR 文字和位置、按用户指定列边界重建图片表格 |

共 36 类任务。教程实践和表单功能在工作台生成步骤或草稿；真正操作仍使用原有浏览器工具与任务授权，敏感输入和最终提交沿用既有人工边界。

## 表格参数与完整性

- 清洗支持空值检查、首尾空格、按指定字段去重、数值/日期解析、明确单位倍率、拆列和合列。转换失败保留原文并报告，不把未知转换成零。
- 筛选支持多个条件、字段选择和排序；精确相等保留值类型，数值大小比较会做明确数值解析。交叉统计采用长表格式，包含分组、交叉字段和聚合结果。
- 比较与关联要求明确且唯一的非空主键，拒绝推测主键。比较分别返回新增、删除和变化；关联支持左关联、内关联和全关联。
- 每份处理表最多 100 列、5000 行，任务最多 10 份材料。超限明确拒绝，不静默截断运算。空结果和真实零值分别处理。
- 统计产生本地 SVG 图；表格产物包含 CSV、Excel 和 JSON。CSV 保护公式样式文本，Excel 以文本保存原始字符串。
- 界面预览限制为 1000 行及约 160KiB，并标出总记录数。完整记录保留在任务产物中；继续处理会读取宿主生成的完整 JSON，不把预览当作全量。

用户可加入最多 30 份材料，内存材料总量限制为 16MiB。单次外部材料传输限制约 230KiB，单次本地处理材料总量限制 8MiB；模型判读上下文限制约 128KiB。超限时缩小任务范围，不能据此宣称已分析所有材料。

## 原文引用与学习记录

分析段落须提供当前材料的连续原文摘录。模型选择材料中的证据编号，由宿主还原原文并检查来源身份，避免模型改写摘录中的空格或换行。自测题和复习卡必须包含题目、参考答案、来源及原文依据；空题目、未知证据或无依据输出拒绝完成。

引用通过只说明结果关联了原文，不独立证明解释、推理或答案正确。结果区分本地计算、来源核对、OCR 候选和部分完成，不将模型自述标为独立事实验证。

练习先隐藏参考答案。提交作答后可以对照答案并自评；自评明确标记，不作为自动判分或已掌握证明。保存记录后可读取问题、自己的答案、参考答案和原文依据，或加入材料继续复习。学习记录按浏览器来源隔离。

## 图片表格

图片处理使用 macOS Vision，在本机运行，不调用模型。输入为不超过 150KiB、1600 万像素的 PNG。当前页的 Canvas 只读取可见且不属于隐私/编辑区域的图像，最多三张；跨源保护、过大图像或无效图像明确拒绝，不绕过浏览器限制。

图片表格须填写列名和列分隔位置。例如两列可填列名 `Item,Qty`，边界 `0,50,100`；界面将百分比转换为归一化位置。可跳过表头行，并设置行聚类容差与最低置信度。

OCR 原始文字、位置及结构核对明细分别保存。跨列文字、未归列文字、低置信度、空格和缺失单元格保留为待核对项。没有识别出的字符不能补造；实际合成测试中孤立的 `0` 曾未被 Vision 返回。即使未发现异常，也不把结构重建标为独立验证正确。

## 推荐规则与插件来源

推荐消费当前允许观察的页面结构、明确选区、材料集合、用户方向和执行结果。没有正文材料时，可以出现“先读取再处理”的卡片；这类卡不会自动采集或派发任务。学习建议需要明确学习方向，不根据停留推断学习意图。

推荐先校验对象、范围、参数、能力状态和反馈，再按工作缺项、结果接续、对象匹配、就绪情况、显式偏好、有效证据和已验证效果排序。模型可在已有候选中辅助排序，不能生成授权或跳过前提。

### 旧模型自由建议迁移

模型不再主动创建 `general.task` 或其他无法映射的任务卡；日志使用既有 `output_repaired` 事件记录 `error_type: unmapped_task`，不记录任务正文。合法的已注册流程和 SEO 模板仍按原对象、场景及触发资格推荐；`candidate_order` 只能引用本轮已发送的候选 ID，不能带入新任务或参数。

迁移前无法映射的待办保留原文，只读展示，不占十张主动推荐卡的名额，不自动执行，直接调用执行入口也会拒绝。内部标记为 `readonly`，界面仍在待办区展示只读说明；后续安装同名模板也不会自动转换旧任务。需要执行时，用户可从原有自由任务输入入口主动输入并确认任务。显式用户输入的 `general.task`、已排队/执行中的任务及已有结果保留原执行合同；结果重试仍走原有回执检查和必要的二次确认，不会自动重放。

通用任务与功能插件任务统一进入“建议”区，合计最多十张主动推荐卡，不再从顶部单独打开通用任务列表。用户显式准备的任务标记为“已准备”并保留；进行中任务和已有结果保留各自分区。稍后默认抑制一小时；不再推荐某类任务使用显式隐藏偏好，可在任务配置中恢复。

界面和模型上下文只展示最近八条反馈，当前工作内仍有效的反馈继续抑制对应建议。最多保留二百条有效反馈，达到上限时明确提示，不丢弃旧记录或提前恢复被抑制的卡片。导航后仅用当前页面的有效线索推荐，不沿用旧页的标题、选区或表格线索。

目录覆盖已登记功能包、技能声明、已有发现快照和已绑定工具。声明不完整、加载失败、来源未刷新或尚未适配均明确列出；不把“已安装”当作“可执行”。MCP 发现使用完整有界分页，能力就绪检查包含版本、作用范围和新鲜度，刷新失败不把半份目录发布为完整目录。

插件可在既有 `flows` 内增加 `recommendation`：

```json
{
  "recommendation_contract": 1,
  "task_type": "case.review",
  "scope": "page",
  "subject_kinds": ["business_object"],
  "intent": ["verify"],
  "output_kind": "records",
  "completion": {"zh": "返回实际核对记录和缺项", "en": "Return checked records and missing information"}
}
```

该片段放在一个已存在且可运行流程的 `recommendation` 字段中，不是独立包。旧包缺省仍按专用页面规则处理。仅声明通用范围但没有执行对象适配的插件保持待适配；不会借通用推荐扩大站点或对象权限。具体字段见[机器格式](fbl-pack.schema.json)与[功能插件标准](design/adapter-packs.zh-CN.md)。

## 功能插件管理

从主界面或设置打开独立的“功能插件”页面。列表会提前检查本机声明、模板、受管文件完整性、依赖命令、脚本和当前绑定状态；状态灯同时有文字说明，不只依靠颜色区分。可查看检查明细、重新检查，或进入对应能力的配置界面。

| 状态 | 含义与处理 |
| --- | --- |
| 未安装 | 安装内置包，或提供可信本地包的绝对路径 |
| 已安装 · 待配置 | 已保留包文件，仍需连接 Agent、确认来源或配置绑定 |
| 检查中 | 等待本次本地检查回执，期间防止重复操作 |
| 本地先决条件通过 | 本机检查已通过；服务、登录和实际数据仍在具体任务中核实 |
| 异常 | 查看缺失命令、脚本、模板或无效声明等具体原因后修复 |
| 需更新 / 重新检查 | 元数据或绑定声明已过期、发生变化，需要刷新并重新核实 |

安装和卸载复用受管包事务，须关闭协作并等待任务结束；卸载前有确认。本地修改、外部目录和未受管文件继续保护，不直接覆盖或删除。单独检查允许协作开启时执行，不运行包命令、不打开网页或调用付费服务；检查通过不会生成任务执行成功回执。

自定义 MCP 工具必须由有效安装包明确声明，经完整合同检查及显式来源确认后才能就绪。确认记录关联同一配置、服务、工具、包版本及合同，不能借用另一配置的同名工具记录。

## 验证与边界

离线测试使用合成材料、临时目录和受控模型回执；本机 Vision 测试只说明合成图片的实际识别结果。真实 Chrome 渲染验证使用隔离的合成侧栏与交互页面，不等于已安装扩展、真实账号或真实模型端到端验收。

实际安装、模型服务、第三方站点、外部接口、剪贴板和系统文件打开行为应分别验收。安装、同步、push 和发布不随代码测试执行。
